# C4R Platform - Project Information

## 📋 Project Overview

**Project Name:** C4R Platform  
**Type:** Car Rental Platform (تأجير سيارات)  
**Market:** Saudi Arabia (السعودية)  
**Live URL:** https://c4rplatform.vercel.app  
**GitHub:** https://github.com/redasalem/c4rplatform.git

---

## 🛠️ Frontend Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** JavaScript (NOT TypeScript)
- **Styling:** Tailwind CSS
- **Icons:** lucide-react
- **Deployment:** Vercel

---

## 🎨 Design System

**Theme:**
- Dark background (Black/Dark Gray)
- Primary color: Orange
- Text: White/Light Gray

**Language:**
- Primary: Arabic (RTL)
- Secondary: English

**Approach:**
- Mobile-first
- Card-based layouts
- Backdrop blur effects

---

## 📏 Tailwind Breakpoints

```
default (0px+)   → Mobile
sm (640px+)      → Mobile Large
md (768px+)      → Tablet
lg (1024px+)     → Laptop
xl (1280px+)     → Desktop
2xl (1536px+)    → Desktop Large
```

## ⚠️ Critical Rules

**DO ✅**
- Only modify className (Tailwind)
- Keep all text and links
- Use smooth transitions
- Mobile tap targets >= 44px
- Use JavaScript (NOT TypeScript)

**DON'T ❌**
- Delete any words/links
- Change logic/state/props
- Rewrite from scratch
- Use TypeScript
- Break existing functionality

---

## 📱 Mobile Goals

Make mobile feel like a Native App:
- Bottom navigation (5 tabs)
- Large tap targets
- Smooth animations
- Clean UI
- Fast loading
